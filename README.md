# Project 1 — Responsive Frontend Interface

DecodeLabs Full Stack Industrial Training Kit (Batch 2026)

## Goal
Create a responsive frontend interface for a simple web application (DecodeLabs Intern Portal).

## Key Requirements
- HTML, CSS, and vanilla JavaScript only
- Responsive layout for mobile, tablet, and desktop
- Clean, user-friendly UI

## Features
- Intern directory with search/filter
- Add-intern modal form
- Responsive navbar with mobile menu toggle

## Run
Open `index.html` directly in a browser, or serve it locally:

```bash
npx serve .
```
